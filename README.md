# Multi Random One Block

多人随机单方块 Mod for Minecraft 1.21.11 (Fabric)

## 功能

| 功能 | 说明 |
|------|------|
| 单方块平台 | 主世界和下界各生成对应数量的 1×1 独立单方块平台 |
| 初始物资 | 岩浆×5、水×5、树苗×3、红/棕蘑菇各1、土豆/小麦种子/胡萝卜/甘蔗/竹子各2、末地框架×12 |
| 维度专属方块 | 主世界只刷新主世界方块，下界只刷新下界方块 |
| 矿洞模式 | 累计挖掘达到 人数×100 后，输入 `/craftmode cave` 进入矿洞模式 |
| 维度专属生物 | 主世界被动生物，下界所有生物（含烈焰人、末影人等） |
| 防掉落保护 | 站在原始单方块上挖方块时，若因延迟掉下去会自动传送回平台 |
| 人数锁定 | `/setmember` 设定后不可更改 |

## 命令

| 命令 | 权限 | 说明 |
|------|------|------|
| `/setmember &lt;人数&gt;` | OP | 设定参加人数（只能设定一次，立即生成平台） |
| `/mrob info` | 所有人 | 查看当前状态、模式、挖掘进度 |
| `/craftmode cave` | OP | 进入矿洞模式 |
| `/craftmode normal` | OP | 恢复普通模式 |

## 安装要求

- Minecraft 1.21.11
- Fabric Loader &gt;= 0.16.0
- Fabric API
- Java 21+
